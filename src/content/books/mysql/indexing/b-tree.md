# B+ 树索引

InnoDB 存储引擎默认使用 B+ 树作为索引结构。

## 为什么选择 B+ 树

相比于 B 树，B+ 树的优势在于：

1. **所有数据都在叶子节点**：范围查询更高效
2. **叶子节点形成链表**：便于顺序遍历
3. **非叶子节点只存 key**：可以容纳更多索引项，降低树的高度

## 聚簇索引 vs 非聚簇索引

- **聚簇索引**：叶子节点存储完整的行数据
- **非聚簇索引**（二级索引）：叶子节点存储主键值

```sql
-- 聚簇索引查询（直接定位数据）
SELECT * FROM users WHERE id = 1;

-- 非聚簇索引查询（可能需要回表）
SELECT * FROM users WHERE name = '张三';
```
